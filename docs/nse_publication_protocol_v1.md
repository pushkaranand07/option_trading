# Protocol: when NSE files appear in the evening

> **Status:** Written 2026-11-01. **Skipped for now, by the user's decision of 2026-11-01.** By hand if ever used; nothing automated, no new collection.
> **Scope:** 20 evenings of noting when each file is public, because D-1 timing rests on publication times that are UNVERIFIED historically.

**This does not reopen the closed model suite.** Its result stays as stated, whatever this shows. Using evening data in a future test would need a new pre-registered line, and your decision.

## What to do

On 20 trading evenings in a row, or as near as you can, from about 15:30 until each file appears:

1. Open NSE's reports page in a browser, as you would normally.
2. Note the time you **first see** each file for that day. Don't download anything for this.
3. Check at no more than one look every 15 minutes, so that a time is good to 15 minutes.

## How it will be read

- For each file: earliest, median and latest time across the 20 evenings, in a table only.
- The question: was every file public before 09:15 the next morning on all 20 evenings?
