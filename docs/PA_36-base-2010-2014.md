## 1. Problem

Batch c adds 2010–2014 to the stored base, with a calendar built from NSE's own circulars (NSE's holiday API has none
for 2010 and an incomplete 2011). The user also asked to make the research loader refuse live tables, guard the lot
clean-up against oscillation, audit the protected range by equality only, and, after approving two parser changes,
prove the American-option cutover from NSE's circular and keep the 2015–2026 tables identical when the new column is
added.

## 2. Findings

**Cutover from NSE's circular, not inferred:** NSE/faop/16165 (2010-10-28): stock options expiring on 2011-01-27 and
after are European; the 2010-11-25 and 2010-12-30 expiries stay American (NSE/faop/16588: all F&O options European from
then). Checked on every raw row: 0 American rows expire on or after 2011-01-27; 0 of the 8,094,786 European stock-option
rows in 2010–2011 expire before it. Index options were European throughout.

**2012-05-14:** NSE serves only this re-issued version (a fresh download is byte-identical; other URL forms return 404).
The original version is UNVERIFIED, so no comparison of original and re-issued file was possible;
its CSV is dated 2012-05-22 inside the zip. Against NSE's market activity report for the day, 1,539 traded options match
on close and open interest; contracts differ on 75 index-option rows (the bhavcopy equal or higher, median +0.3%). Used,
as the only bhavcopy of the day; details in the [data catalog](data_catalog.md).

  `<raw>/fo/checksums_2010_2014.csv`. Weekends were probed with the F&O file itself (no index files before 2015).
- Calendar: 31 F&O circulars (yearly holiday lists, extra and revoked holidays, 7 Saturday live sessions, 5 Muhurat
  sessions, the European-style circulars), each kept raw with SHA-256 in `<raw>/circulars/manifest.csv`, turned into

- Sessions per the circulars vs files: 2010 252/252, 2011 247/247, 2012 251/251, 2013 250/249, 2014 244/244. Every
  special and Muhurat session has a file; no file falls on a non-session. **One unexplained gap, 2013-10-09**: F&O
  bhavcopy 404 in both forms while the market activity report and MTO exist. Documented as an archive hole; **check
  kept FAIL**.
